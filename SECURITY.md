# Security policy

Only the latest stable release is maintained. Please update before reporting
a problem. This is a hobby project; response and fix times are not guaranteed.

## Report a vulnerability

Use **Security and quality → Report a vulnerability** on this repository to
send a private report. Private vulnerability reporting is enabled. Explain
the affected version, impact, and how to reproduce the problem using synthetic
data where possible.

Do not include real conversations, passwords, cookies, tokens, or Playwright
browser profiles in public issues or pull requests. Redact identifying details
from logs. If the private reporting option is unavailable, open a public issue
asking for a private contact without describing the vulnerability.

For ordinary bugs and feature requests, use the public issue forms instead.
